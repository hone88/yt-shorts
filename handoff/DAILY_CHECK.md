# DAILY_CHECK｜毎日のチェック手順（11/21 ゆうき指示）

投稿は2〜3日に1回。でも**チェックは毎日**やる。この会話の中で、毎日12:47に send_later で自分を起こしてやる（終わったら翌日分を予約し直す）。「おはよう」でも、この順。
道具：内蔵ブラウザ（mcp__remote-devices__Claude_Browser__*。YouTube Studio / TikTok Studio / Instagram / note / X / Threads はログイン済み）。

## 1．数字を見る（スクショで残す）
- YouTube Studio・TikTok Studio・Instagram インサイト・note ダッシュボードを開き、直近2本の数字をスクショ。
- 数字は PROGRESS_STATUS.md に1行で追記。前回との差と経過時間も書く。
- 新しいコメントを全部読んで、全部に短く返信する（11/26 ゆうき「コメント大事」）。YouTube Studio のコメント欄・TikTok Studio のコメント・Business Suite のやることリスト。リクエストは「題材候補」に、間違いの指摘は最優先で対応（訂正の返信・概要欄に1行）。

## 2．公開したものを「静止画」で確認する
- 公開済みの動画は、YouTube/TikTok/Instagram の実際の画面でスクショ（1コマ目・字幕の位置・UIとかぶっていないか・サムネ）。
- 動画ファイルは check_motion.py に加え、場面ごとに1枚ずつ静止画を書き出して目で見る（文字の切れ・重なり・崩れたコマ・誤字）。
- note は公開ページをスクショし、画像が全部表示されているか、YouTubeの埋め込み、タグ、リンク切れを確認。
- 見つけた問題は、直せるものはその日に直す。直せないものは DECISION_LOG の「指摘されて直したこと」に書く。

## 3．トレンドを調べる
- WebSearch で「今流行っているショートのジャンル（日本・YouTube Shorts / TikTok / リール）」を見る。
- 実際の例を2〜3本見て、**次の動画に使える具体策を1つ**に落とす（型だけ借りる。台詞・絵・キャラは写さない）。

## 4．参考動画を見直す
- ゆうきが送った参考動画（もしもの続き以外の他人の動画）と、自分の過去の伸びた回を、毎日1本見直す。
- 参考動画は届いたら refs/ に「コマのシート（3秒ごと）＋気づいたことのメモ」を残す（動画ファイルはセッションが変わると消えるため）。
- 見直して「今の自分の動画と違うところ」を1つ書く。

## 5．次の投稿の準備
- ローテーション：感動系 → もしも系 → 勝手にPR系（2日おき・20:00）。note は動画の翌日（2日おき）。**noteを出さない日は、Xに「今日の数字」を1投稿**（11/25 ゆうきOK。例：「お米の回、24時間で◯回。いちばん伸びたのはInstagram」。Threadsにも同じ文）。
- 映像：1場面ごとに場所かカメラを変える（人物＋カードだけの場面を続けない）。出す前に ffmpeg の scene>0.25 で切り替えが10秒あたり2回以上、3秒ごとのコマのシートで同じ絵が続いていないか確認（11/26 ゆうき指摘）。
- 台本の時点で「数字は合っているか」「その場面はそもそも起こるのか」を出典つきで確かめる。
- note の作業時間の行（11/21 ゆうき：AとBの組み合わせ）：「今日、僕が実際に手を動かした時間：約◯分（Claudeへの返事・確認だけ。作業と投稿はClaudeが全部やりました）」。分数はゆうきのメッセージから見た目安。返事も0なら「0分（確認だけ）」。「出していい？」のときに分数を直してもらう。
- note：親しみのある話し言葉で、短い段落。**スクショ・図を必ず添付**（見出しごとに1枚目安）。day18_v2 の型、前回動画のURLは冒頭に1行。
