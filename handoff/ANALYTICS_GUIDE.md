# ANALYTICS_GUIDE｜数字の見方

## 1. 見る指標と意味
| 指標 | どこで | 何が分かるか |
|---|---|---|
| 視聴を継続（%）／スワイプ | YouTube エンゲージメント | 最初の数秒で止まってもらえたか（**一番大事**） |
| エンゲージビューの伸び方 | YouTube エンゲージメントのグラフ | 何時間で横ばいになったか（2時間で止まる回と、2日伸びる回がある） |
| 視聴者維持率のグラフ | YouTube 視聴者維持 | どの秒で離れたか（最初の数秒・最後の問いかけ） |
| 平均視聴時間・割合 | YouTube / Instagram / TikTok | 中身を最後まで見たか |
| 登録者・フォロー | 各SNS | 1本でファンが増えたか |
| いいね・コメント・リポスト・保存 | 各SNS | 反応。コメントは次の題材になる |
| 検索からの流入 | YouTube トラフィックソース | 時間がたっても見られる力 |
| インプレッション・PV・スキ | note ダッシュボード | 記事の読まれ方 |

- **公開からの経過時間をそろえて比べる**（例：「24時間で2,001回」）。再生数だけで良し悪しを決めない。
- 取れない指標は埋めない。スクショの期間（何日〜何日）を必ず書く。

## 2. これまでに分かったこと（数字はメモリと過去のnoteより）
- 最初の2秒で決まる：冒頭を作り直した重力の回で継続 25〜31% → 48.7%（10/31）。
- 明るい1コマ目の回は継続40%超、暗い1コマ目の回は31%以下（11/3）。
- 多くの回はエンゲージビューが公開後2〜7時間で横ばい。**カメラを動かし続けた回（穴・すいか）だけ伸び続けた**（穴 45時間、すいか 2日目も上昇）。
- すいか（コメントのリクエスト）：継続56.2〜56.3%で過去最高、2日で2,174回・登録+5。
- 摩擦：同じ作り方でも継続47.6%、エンゲージビュー581で2時間で横ばい。Instagramもすいかの約6割→**1コマ目に目に見える物がない**のが原因という仮説【暫定】。11/9の車の回で確かめる。
- 最後の問いかけの場面で毎回大きく離脱する → 終わりは短く。
- Instagramは1日遅れで伸び、最近は毎回2,000〜4,000回。YouTubeより安定。TikTokは長く約150〜200回で止まっていたが、直近7日は前週の約3倍（1,583回）。
- コメントのリクエストに応えると、またリクエストが来る（1円玉→消しゴム→すいか→車・木・鉄塊・アリ・野球ボール）。
- noteは初期ブーストが切れ、1日のインプレッションは約1,800→約300〜450。流入はnote内が約66%。
- Xは各ポスト2〜数十表示でほぼ伸びていない。Threadsも閲覧20/30日。

## 4. 分析から次の改善へ
数字（事実）→ 前の回との違い（作り方・1コマ目・長さ・題材）→ 仮説（「予想」と書く）→ 次の1本で1つだけ変えて確かめる。
