## 指摘されて直したこと（同じミスをしない）
- 効果音が映像の出来事とずれた → 出来事のコマを測って合わせる。
- 顔が見出し・字幕に隠れた → 静止画に36%/43%/68%の線を引いて確認。
- 赤い×が「いいえ」とずれた → 実測して XFRAC を調整。
- 寄りの場面でカメラと顔の間に物が入って画面が真っ赤 → 寄るときは物を消す。
- noteの表が崩れた → 表は使わず箇条書き。
- noteの内容と実際の予定がずれた → 予定は会話で確認してから書く。
- 字幕の改行（話者が変わるところ）でビルドが落ちた → render.py の wrap を修正済み（11/9）。
