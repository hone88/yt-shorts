# 1. 台本（僕が「次の動画」と言ったら）
- queue に台本が残っていればそれを使う。なければ `channels/moshimo/topics.txt` か僕のテーマで書く。
- `channels/moshimo/prompt.txt` のルールに従う：40〜55秒（230〜320文字）、6〜8シーン、見出し12文字以内、時刻ラベル付き、科学的に正確、言い切れないことは「〜と考えられています」でぼかす、最後は「他に試してほしい『もしも』はコメントで」で締める。
- 1シーン目は「一番派手な場面」を見せてから問いかける（例：「昼なのに、空が一瞬で真っ暗に。もしも、太陽が突然消えたら？」）。最初の2秒で、音なしでも何が起きたか分かるようにする。
- 条件つきの数字には条件を書く（例：「赤道で秒速460メートル」「2センチほど」）。
- 作る前に「本当に注目されるか」を点検する：最初の2秒で止まるか／自分ごとになるか／最後まで見るか／コメントしたくなるか。弱いところは作る前に直す。
- 書いたら queue に push して、内容を表（時刻・見出し・要点）で僕に見せる。

# 2. 背景クリップを用意する（2つのやり方）
## A. 僕が動画生成サイトで作る（実写風）
- 5秒×3〜4シーンずつ、2本に分けた英語プロンプトを出す（例：動画1＝01〜03、動画2＝04〜07）。
- 書き出し：「A 15-second vertical 9:16 cinematic photorealistic video with 3 shots of equal length, no readable signs, text or logos.」
- 同じ生き物が何度も出るときは「Same <生き物> with <色や特徴> in every shot.」を足す。ショート同士で時間帯や天気が食い違わないようにそろえる。
- 届いた動画は次の手順で切る：ffprobe で長さを見る → fps=2,tile のコマ一覧を自分の目で見る → signalstats の YAVG で切り替わりの位置をつかむ → 境目の前後を少し削って切り出す（フェードは前後0.5秒）→ -an、libx264、crf 20、yuv420p → 最初と最後のコマを並べて、別の場面が混ざっていないか確認する。
- 順番や中身が台本と合わないときは、勝手に進めずに僕に聞く。

## B. あなたがコードで作る（マイクラ調・2Dイラスト）
- 実写は作れないので、僕が「マイクラ調で」と言ったらこちら。見本は `moshimo_tools/taiyou_voxel.py`（マイクラ調3D）と `moshimo_tools/gravity_2d.py`（2Dイラスト）。
- 背景クリップは**文字なし**で作る。GitHubの仕組みが文字を入れるので、文字入りだと二重になる。
- 大事なもの（顔・足元・数字のラベル）は、文字に隠れない場所に置く：
  - 150〜430px（上）：チャンネル名・時刻バッジ → 置かない
  - 約700〜820px：見出し → 人の頭はこれより下に
  - 約830〜1290px：何もない → 一番見せたいものをここに
  - 1300px〜：字幕の帯（3〜6行に伸びる）→ 足元や地面のラベルは1290pxより上に
  - GitHubの文字を重ねた試し画像（`render.overlay()` で作れる）で確認する。
- クリップの長さ：声の長さの目安は「ナレーション1文字＝0.135秒＋0.3秒」。クリップはその9割くらいで作る。声より短いクリップはゆっくり再生で合わせてくれるが、長いと後ろが切れて見せ場が消える。
- 手順：一番にぎやかな瞬間を本番と同じ大きさの静止画で出して目で確かめる → 直してから本番 → 場面ごとに1つのMP4（1080×1920・30fps・libx264・yuv420p）を2つ同時に書き出す → 最初と最後のコマを並べて確認。書き出しは360×640で描いて3倍に拡大すると、1コマ約3秒（7場面・約43秒で30〜40分）。

# 4. BGMと効果音を足す（毎回やる）
- 雛形は `moshimo_tools/taiyou_sound.py` と `moshimo_tools/gravity_sound.py`。音はすべてコードで作る（著作権の心配なし）。
- まず完成版から、各シーンの開始時刻を割り出す：`select='gt(scene,0.12)'` で映像の切り替わり、`silencedetect=n=-40dB:d=0.2` で声の区切りを見る（シーンの終わり≒声の終わり＋0.25秒）。
- クリップの中の出来事の時刻＝シーン開始＋クリップ内の時刻×のばし率。のばし率＝max(1, (声の長さ＋0.1) ÷ クリップの長さ)。
- 作り方の考え方：
  - 明るい日常＝ゆるいローファイ（C–Am–F–G）／不思議・冷たい＝短調のパッド＋オルゴールのアルペジオ
  - 大きな変化の瞬間に音を止める・低い「ドーン」を入れる（例：昼→真っ暗でBGMが「ブツッ」と止まる）
  - 映像の動きに合わせて効果音（ヒュン、ブブー、カチカチ→チーン、ピョン、ドスン、パキパキ、泡など）
  - 最後は少し明るい和音や「チーン」で締める
- 混ぜ方（声が出ている間はBGMが自動で下がる）：
  `ffmpeg -i short.mp4 -i bgm.wav -i sfx.wav -filter_complex "[0:a]asplit=2[v][vsc];[1:a]volume=0.85[b];[b][vsc]sidechaincompress=threshold=0.03:ratio=6:attack=20:release=400[bd];[2:a]volume=0.9[s];[v][bd][s]amix=inputs=3:normalize=0:duration=first,loudnorm=I=-14:TP=-1.5:LRA=11[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 44100 -movflags +faststart 完成版.mp4`
- BGMの大きさの目安：BGMだけで -22 LUFS 前後（声は -14 前後）。ebur128 で測って volume を調整する。

# 5. 完成品を確認する
- 長さが60秒未満。
- 音量：volumedetect で平均 -16〜-17dB前後、最大 -1.5dB前後。
- 映像が大きく変わる位置（scene>0.12）が、シーンの境目と、わざと入れた絵の切り替えだけになっている。
- 1〜2秒ごとのコマを並べて目で見る：文字が切れていない、見出しが顔に重なっていない、背景が暗すぎない、順番が台本どおり。
- 音は耳で聞けないので、BGMや効果音の大きさが気になったら言ってほしい、と一言添える。
