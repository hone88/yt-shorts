## 2026-11-21 come.to.yamaguchi「もしも落ちるエレベーターの中でジャンプしたら」（62秒・Instagramリール）
https://www.instagram.com/reel/Df62huTvRs0/
- 流れ：もしも→「落ちる間は人もエレベーターも同じ速さ」→実は宇宙ステーションもずっと落ち続けている→ずっと無重力で遊べる？→スカイツリーのてっぺんから落ちても遊べるのは11秒→もっと長く、横に秒速8キロ→90分で地球1周→ただし降りる階のボタンがない→落ちながらずっとあわてていた→落ち着いて扉が開くと…→雪舟がつくったと伝わる庭（常栄寺 雪舟庭）→縁側に座って眺めるだけでいい→「人生が落ちそうなときは、山口で落ち着いてください。」
- 盗む型（台詞・絵は写さない）：
  1. 物理の「もしも」を2〜3段で大きくする（エレベーター→スカイツリー→宇宙）。1段ごとに数字を1つ（11秒・秒速8キロ・90分）。
  2. **言葉の掛け算で宣伝に着地**：「落ちる」→「落ち着く」。物理の話と場所の魅力を1語でつなぐ。勝手にPR系のオチはこれを最優先で探す。
  3. 字幕は「小さい前置き1行＋大きい本題1行（要点だけ黄色）」。もしもの続きの字幕より文字が少ない。
  4. 最後のカットは地図（県の形）＋場所の名前＋一言の呼びかけ。
- 3Dはリアル寄りの人物。もしもの続きはボクセルのまま、型だけ借りる。
