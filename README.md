# ショート動画 自動生成（2チャンネル）

| チャンネル | 中身 | 頻度 | 役割 |
| --- | --- | --- | --- |
| もしもの続き（`moshimo`） | 「もしも◯◯だったら？」を時間経過で実況する思考実験 | クリップをアップした時 | 再生数を取りに行く |
| ゆうき｜1日1時間AI副業（`ai1h`） | AI副業の実験の実録 | 月・水・金 7:13 | 信頼を作り、noteで売る |

## APIキーなしで回す方法（おすすめ）

台本は Claude（アプリ）が書いて `channels/<チャンネル>/queue/<台本ID>.json` に置きます。
プログラムは queue に台本があればそれを使うので、APIキーは不要です。

### もしもチャンネルの流れ（1本 15〜20分）
1. Claude が台本と、シーンごとの**動画生成用プロンプト**を出す（台本は queue に入る）
2. 好きな動画生成サイトに、シーン1〜6のプロンプトを貼って縦長クリップを作る
3. クリップを `01.mp4`, `02.mp4` … と名前を付け、`20261030` のような台本IDのフォルダに入れる
4. GitHub の `channels/moshimo/clips/` を開き、そのフォルダごとドラッグしてアップロード
5. 自動で「時刻バッジ・見出し・字幕・声」が入った動画ができ、Releases に置かれる

動画の代わりに画像（`03.jpg` や `04.png`）を置いてもOKです。画像はゆっくりズームする背景になります。動画と画像は混ぜて使えます。
クリップも画像もないシーンは、自動で仮の背景になります。クリップの長さはバラバラでOK（声の長さに合わせて自動で切ったりループしたりします）。

### AI副業チャンネルの流れ
台本が queue にあれば月・水・金に自動で動画になります。

## APIキーを使う場合

queue が空のときは、`ANTHROPIC_API_KEY` があれば Claude API で台本を作り、もう一度チェックさせて事実の誤りや言い過ぎを直します。
`OPENAI_API_KEY` があれば、クリップのないシーンにAI画像を作ります。

ゆうきさんは、Releases から動画を見て、YouTube / Instagram / TikTok に予約投稿するだけです（1本2分）。

## 最初の設定（1回だけ、30〜40分）

### 1. GitHub アカウントを作る
https://github.com で無料登録。

### 2. このフォルダをリポジトリにする
1. GitHub 右上の「+」→「New repository」
2. 名前は `yt-shorts`、**Private（非公開）** を選んで作成
3. 「uploading an existing file」から、このフォルダの中身を全部アップロード（`.github` フォルダも）

### 3. APIキーを登録する（使う場合だけ）
リポジトリの「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で登録します。

| Name | 取得場所 | 必須？ |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com | なくてもOK（queue に台本があれば不要） |
| `OPENAI_API_KEY` | https://platform.openai.com | なくてもOK（クリップを自分で作るなら不要） |

どちらも従量課金です。**それぞれの管理画面で、月の利用上限額を必ず設定してください。**

### 4. 動かしてみる
「Actions」タブ →「もしもチャンネル（クリップをアップしたら作る）」→「Run workflow」。
5〜10分で、右側の「Releases」に動画ができます。

## 毎回の流れ（1本2分）
1. スマホの GitHub アプリ → リポジトリ → Releases
2. `upload_memo.txt` の「直した点」と動画を見て、間違いがないか確認
3. `short.mp4` を保存して、各アプリで予約投稿。タイトルと概要欄はメモからコピペ

## 変えたいとき
- **テーマ**：`channels/<チャンネル>/topics.txt` に1行ずつ追加・削除。伸びた型に似たテーマを足すのが一番効きます
- **台本の型**：`channels/<チャンネル>/prompt.txt`
- **声・色・チャンネル名**：`channels/<チャンネル>/style.json`（声を変えたら `voice_credit` も変える）
- **曜日・時間**：`.github/workflows/moshimo.yml` と `ai1h.yml` の `cron`

## 守ること
- 概要欄の `VOICEVOX:◯◯` のクレジットは消さない。声を変えたら、そのキャラクターの利用規約も確認する
- もしも動画は「※思考実験です」の注記を残す。リアルなAI映像を使う回は、YouTubeの「改変または合成されたコンテンツ」の開示をオンにする
- 同じ型の量産は「非オーセンティック」と判定されやすい。コメントで来たテーマを使う、ときどき自分の声やコメントを入れるなど、人の手を入れる
- APIで自動アップロードする機能は、Googleの審査が必要なので今は入れていません
