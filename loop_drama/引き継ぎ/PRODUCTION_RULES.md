# PRODUCTION_RULES — 制作ルール（実際に再現できる粒度で）

出典：完全版企画書（5・28・31〜37・40章）、`loop_drama/注意点.md`、会話での指示。

---

## 1. 内容のルール【確定】
### 1-1. 使わない表現（支部・ユニットの指摘：11月3日）
- 「選考会は落とす場じゃない」 → 書かない・言わない。「落とされる／落とされない」と描くこと自体がタブー。
- 「2次選考会は早いほどお得」「早いほど選べる」 → 使わない。
- 「活動先は先着順で埋まる」 → 使わない。活動先は **1次選考会の際にスタッフから紹介され、決定する**。自分で「この議員がいい」と希望する学生もいる（11月4日 代表・広報の回答）。
- 「インターンに参加すれば就活で勝てる」 → 使わない。
- 「オンライン説明会は1対1だから安心」を主な訴求にしない（実際は基本1対1だが強調しない）。
- 「カメラON必須」 → 使わない。カメラをつけてと頼む場面も作らない。
### 1-2. 政治・知事
- 超党派。政党を思わせる色・ロゴ・バッジ・旗・ポスターは出さない。実在の議員・企業は出さない（企業は架空・社名もロゴも出さない）。
- 知事：顔・名前・声のモノマネなし。知事面談は「予定が合えば可能」。ゴール・山場にしない。第16話等で**ピクセル絵の後ろ姿**はOK。番外編で過去の知事面談の写真・文章は**写っている方の許可があればOK**。
### 1-3. 描き方
- 議員・NPO・受け入れ先を悪く描かない。怒らせない。待たせる場面でも「静けさ」で重さを出す（第4話）。
- 事件は**カナタ自身の緊張・行動**から生む。小さく、見ていて面白く。
- カナタを急に成長させない。「すごい経験をしたから成長」ではなく「自分で考えて一歩動いたから少し変わった」。
- 「インターン＝就活対策」だけの印象にしない。
- 実際の活動内容と矛盾させない。めったにない場面は読み上げなしの小さな※（例「※実際には、学生が1人で訪問先へ行くことはほとんどありません」）。
- 宣伝は最後の数秒と投稿文だけ。インターンの説明はセリフ・場面の中に自然に。
- 視聴者に選ばせる分岐はやめた（基本は一本道）。問いかけは「あなたならどうする？」型。【確定（完全版企画書35章）】
### 1-4. 参加フロー（物語はこれに合わせる）【確定】
説明会 → ES・IS記入 → 1次選考会（学生とスタッフ。興味・やりたいこと・伸ばしたい力。基本は広島市青少年センターで対面、オンラインもあり）→ スタッフがES・ISを活動先へ提出 → 2次選考会（**受け入れ先の議員・NPO等と日程を合わせて基本対面**。これからの活動を決める。話す内容は1次でも話した興味・やりたいこと・なぜやりたいのか）→ 活動先決定 → 1月末キックオフ（必須）→ 2月1日〜活動 → 2月末ハーフタイム → 未来自治体ほか → 3月末最終報告会 → 3月31日終了。
- 2次選考会は「行けないなら連絡すれば日程をずらせる」とは描かない（実際の議員・活動先が日程を合わせて来るため）。【確定：11月4日】
- 議員インターン：あいさつ回りは**議員さんに同行**。1日6〜7か所のことも。事務所のインターン生は基本2〜3名。議員さんが車を運転して移動することもある（第7話）。10時スタートが目安、午前のみ・午後のみも可（活動先による）。
- 任意イベント（企業訪問・地域イベント・公開討論会・議員交流会など）は「参加は自由」。案内は**インターン生のオープンチャット**に支部スタッフから届く（第8話の描写。アプリ名・ロゴは出さない）。

## 2. 映像【確定】
- 縦 1080×1920、30fps。マイクラ調ブロック3D（`g3d.py`）。
- **人物に寄る**。目の高さのカメラ（床から1.4〜1.8）。顔のアップは頭が画面の約1/4〜1/3（2〜2.4ブロック）。背中越し／顔アップ／2ショットが基本。全身が小さい引きばかりにしない。ただし**場所が分かる引きの画**も要所で使う（地域イベント・キックオフ会場など、ゆうきさんの指示）。
- 議会傍聴は**傍聴席（横の高いところ）から議場を見下ろす**画。議員さんは演台・議長席を向いて話す（カナタに向かって話しているように見せない）。傍聴中のカナタは**いすに座らせ**、画面の左（議場側）を向かせる（第8話の修正）。
- 世界が止まったら色を抜き、**カナタとトケイだけ色を残す**（`render(..., keep={"kanata","tokei"})` → `O.desat(img, 0.95, mask)`）。
- キャラクターは `characters.py` の定義だけで描く（色・寸法・8×8の顔）。表情：カナタ normal（半目）/open/shock/blank/smile/sleep/**resolve（決心：眉を下げ口を結ぶ。11月4日追加）**。
- 布団にくるまる場面は `ep4.blanket()` の布団ボックスで顔だけ出す。
- 反省・決意の場面で笑顔にしない。

## 3. 文字【確定】
- 日時：画面上部中央。**枠の上端は上から260px**（`ep1b.CLOCK_Y = 260`）。日付50px・時刻140px（黄。世界が止まると赤：`flash=1.0`）。学年の札（大学1年＝青、大学4年＝赤）。その下に「残りループ n」（`O.counter(img, n, pulse)`、`CLOCK_Y+296`）。減る瞬間は赤く光らせる（pulse）。
- 時計の下の追加の札：`CLOCK_Y+372〜380`。**場所・状況の札は大きく**（第8話 `bigbadge`：66pxの白字・色付きの丸札。例「議会を傍聴中」「地域のイベントに参加中」「事務所で活動中」）。
- 字幕：Noto Sans CJK Black 72〜76px、白＋黒縁、重要語は黄（台本では `[ ]` で囲む）、1行12文字前後・最大3行、話者の名前札つき（`O.SPEAK`）。基準位置 y≈1400（行数に応じて上に）。
- つかみの文字：0秒から画面中央（y≈1040〜1120）に大きく。2.4〜4.4秒でタイトル「ガクチカ・ループ 第N話／タイトル」。
- 説明カード（ルールなど）は画面の半分を使って大きく。キーワードは赤。
- 安全域：上から約240pxと下から約300px、右端はInstagramの表示で隠れる。文字同士・文字と顔が重ならないか静止画で必ず確認。

## 4. 音【確定】
- 最初の0.5秒以内に低い「ドン」（`sfx_boom`）。声は0.35秒から。
- 最初から最後まで途切れさせない（BGMか環境音）。0.1秒ごとに測って **-45dB未満がないこと**（最後のフェード以外）。無音は「世界が止まる」演出の0.5〜1秒だけ。
- 場面転換は共通の `sfx_transition`（シュッ→ドン）を切り替えの0.45秒前から。**第8話では転換音と環境音（amb_room/amb_crowd）を0.8倍にした**（ゆうきさんの指示「大きいから80%に」）。他の話に広げるかは【未決定】。
- 答え・山場の直前は声を0.8〜1秒止めて `sfx_riser` → 一番大きいドン。
- 場面の空気でBGMを替える：明るい（`bgm_morning`、締めは `bright=True`）／静か（`bgm_sparse`）／暗い（`bgm_dark`）／重い（`bgm_heavy`）。`bgm_dark`・`bgm_heavy` は3秒未満を作れないので `A.bgm_dark(3.6)[:int(n*A.SR)]` のように切って使う。
- 時間の場面は `sfx_stopwatch` / `sfx_tick`、面接は秒針と心臓（`sfx_heart`）。世界が止まる `sfx_freeze`、巻き戻し `sfx_glass`→`sfx_rewind`→`sfx_reverse_swell`。
- 声が出ている間はBGMを `duck` で下げる（消さない）。仕上げは loudnorm I=-16 / TP=-1.5、AAC 192k。
- 声：VOICEVOX。速さ1.15。話者番号は STORY_BIBLE の表。

## 5. 構成・テンポ【確定】
- 冒頭コールドオープン → 2.4秒でタイトル → 本編 → 問いかけ＋次回予告＋申込案内＋創作ドラマの一文（最後の画面 `P.end_scene` の上に文字）。
- 長さ：これまで51〜85秒。**第8話でゆうきさんが「1分20〜30秒くらい、余裕を持ってゆっくり」と指示**。以降の話もこの長さを基本にするかは【要確認】（第5話の指示は50〜60秒だった）。
- セリフの間：第8話は `seq(..., gap=0.32)`。困る・どもる場面は1秒前後の間、世界が止まる前は約2秒の沈黙。

## 7. 作業手順（毎話）
1. 完全版企画書の該当章＋このルールで台本を作り、**40章のチェックリスト**で自己点検（PDCA）。台本を求められたら先に出す。
2. `tools/voice/loop_epN.json` を書いて push（`git pull --rebase` してから）。push で `voice.yml` が走らなければ `gh api -X POST repos/hone88/yt-shorts/actions/workflows/voice.yml/dispatches -f ref=main -f "inputs[file]=loop_epN.json"`。終わったら `bash tools/get_voice.sh loop_epN loop_drama/voice/epN`。
3. `epN.py`（映像）を前の話をひな形に作り、各場面の一番にぎやかな瞬間を静止画で確認（顔の切れ・文字の重なり・時計との重なり）。
4. `python3 epN.py build` → `python3 mix_epN.py`。
5. 1〜3秒ごとのコマを並べて確認、0.1秒ごとの音量を測る（-45dB未満がないか）。
6. 投稿文を書き、`/mnt/user-data/outputs/` にコピーして渡す。`git add -A loop_drama && git commit && git pull --rebase && git push`。
