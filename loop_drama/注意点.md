# ショート動画づくりの注意点（ゆうきさんの指示のまとめ）

これまでの動画づくりでもらった指示と、そこから決めたやり方。新しく作るときは、最初にここを読んでから始める。

## 1. 企画・物語
- **本当に注目されるかを、根本から疑ってから作る。** 「良さそう」で止めず、見る人の動きで点検する。
  - 最初の2秒で止まるか（音を消しても何の場面か分かるか）
  - 自分ごとになるか（「あなたは？」と見ている人に聞く）
  - 最後まで見るか（説明は短く、数字で緊張を作る）
  - コメント・シェア・続きを追うか（A/B投票、前回までの1行、プロフィール固定）
  - そもそも届くか（スタッフ・経験者のストーリー共有、公式アカウントのリポスト）
- 設定は現実の感覚でおかしくないかを確かめる（例：4年を18回やり直すのは長すぎる → 4か月×3回に）。
- 渡された情報は全部入れなくていい。物語に自然に出てくるところだけ使い、残りは捨てる。
- 宣伝は最後の数秒と概要欄だけ。広告っぽくしない。
- 団体の趣旨（社会を知る・人とつながる）とずれる押し出し方はしない（例：インターン＝就活の道具、にしない）。

## 2. 映像（カメラ・キャラクター）
- **人物にもっと寄る。** 斜め上からの見下ろしはやめ、目の高さのカメラで撮る。
  - 背中越し（相手の顔を見せる）／顔のアップ（表情を見せる）／2ショット を基本にする
  - 顔のアップは頭が画面の約1/4〜1/3（2〜2.4ブロック離す）
- **キャラクターは定義書（`characters.py`）からだけ描く。** 部品の寸法・色・8×8の顔の模様・表情差分を固定し、毎話そろえる。見た目を変えるときは定義書だけを直し、設定画（`設定画/`）を作り直す。
- 主人公は灰色の世界で一目で分かる色（赤いパーカー）。止まった場面は主人公だけ色を残す。
- 全身が小さく映る引きの絵ばかりにしない。

## 3. 文字
- 参考にしたリールと同じくらい、**大きく・太く・読みやすく**。
- タイムリープものは**日時を強調する**：上の中央に大きく（時刻170px・黄色、止まった瞬間は赤）、学年の札（大学4年＝赤、大学1年＝青）。
- 字幕は76pxの極太・白に黒い縁、大事な語だけ黄色。1行12文字前後・2行まで。話している人の名前札を付ける。
- **ルールなど大事な説明は、画面の半分を使うカードに太字で大きく**、キーワードは赤。
- 1コマ目からつかみの文字を画面中央に大きく出す。
- 文字同士・文字と吹き出し・文字と人物の顔が重ならないかを、静止画で必ず確かめる。
- 下から約300pxと右端はアプリのボタンで隠れるので、大事な文字を置かない。

## 4. 音
- **効果音とBGMを効果的に入れる。** すべてコードで自作する（著作権の心配がない）。`audio.py`
  - 緊張：低い持続音＋時計の秒針＋心臓の音／止まる瞬間：低い衝撃＋耳鳴り、そのあと無音
  - 不思議：オルゴールの短調アルペジオ／巻き戻し：ガラスのひび＋テープの逆回転＋逆再生の盛り上がり
  - 日常：ゆるいローファイ（C–Am–F–G）／通知音・ポップ音・カードが出る音
- 声が出ている間はBGMを自動で下げる（ダッキング）。全体は -16 LUFS 前後・最大 -1.5dB。
- 声はVOICEVOX。キャラごとに声を固定（カナタ＝白上虎太郎、ミオ＝春日部つむぎ、トケイ＝ずんだもん、面接官＝青山龍星、森下議員＝玄野武宏）。概要欄にクレジット必須。

## 5. 事実（ドットジェイピー広島第一支部）
- 全国32拠点・のべ4.5万人。広島第一支部は「知事面談」（市議ではない）。
- 議員インターンは10時スタートが目安。学生の希望で午前だけ・午後だけも可。
- 春インターン 2月1日〜3月31日、申込締切12月31日。1次選考会は随時で、希望の活動先は後半に埋まる。
- 説明会は対面もあるがオンラインが多い。案内は口コミ・インスタ・DM・声かけ・チラシ・参加者の友達紹介（バイラル）。
- 流れ：説明会→1次選考会→2次選考会→ESIS→キックオフ（1月末・必須）→本番→ハーフタイム→未来自治体（3月中旬の水曜ごろ）→最終報告会。修了認定証あり。3年生以降はキャリアアドバイザー。

## 6. 守ること
- 超党派：政党・実在の議員を思わせる色・バッジ・ポスターは出さない。議員は架空。
- 知事は顔・名前・声のモノマネを出さない。「知事に会えるのはここだけ」と読める言い方をしない（県の意見交換会など、ほかにも場がある）。
- 「フィクションです」「特定の政党を支持しない中立的な団体です」を概要欄に。
- 個人名が入った一時的なファイルは、確認が済んだら消す。

## 7. 作り方の手順
1. 台本を書く → `tools/voice/<名前>.json` を置いて push すると、`voice.yml` がVOICEVOXで声を作り、`voice-out` ブランチに置く（Actionsの成果物はこの環境から取れないため）。行ごとに `speaker` を指定できる。
2. 一番にぎやかな瞬間を静止画で出して確かめる（文字の重なり・顔が切れていないか・人物の大きさ）。
3. 場面ごとにMP4を書き出し（2つ同時）、`-c copy` でつなぐ。
4. 音は `mix1.py` のように声＋効果音＋BGMを作り、映像はそのまま `-c:v copy` で差し替える。
5. 完成版から1〜2秒ごとのコマを並べて最終確認し、長さ・音量を測ってから渡す。
6. 出力は極力そのまま使える完成版で渡す。
